# RPG Adventure - Telegram Mini App

> Игра работает как Telegram Mini App и в обычном браузере для локальной разработки.

## Проверки качества

Требуется Node.js 20 или новее. Зависимости устанавливать не нужно:

```bash
npm test
```

Тесты проверяют экипировку, расход зелий, расчёт урона, эффекты навыков, целостность сохранений и безопасный вывод имени персонажа.

## Навыки классов

- Воин: мощный удар и защитная стойка (снижение следующего полученного удара на 75%).
- Маг: огненный шар и заморозка (пропуск следующего хода врага).
- Лучник: двойной выстрел и яд (три хода периодического урона).

Каждый навык выбирается отдельно во время боя и требует указанное количество маны.

Противники используют разные тактики: волки чаще атакуют мощно, гоблины истощают ману, скелеты могут восстановить здоровье, а боссы чередуют усиленные атаки и истощение. Активные боевые эффекты отображаются над кнопками действий.
