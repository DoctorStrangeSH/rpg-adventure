# RPG Adventure - Telegram Mini App

> Игра работает как Telegram Mini App и в обычном браузере для локальной разработки.

## Проверки качества

Требуется Node.js 20 или новее. Зависимости устанавливать не нужно:

```bash
npm test
```

Тесты проверяют экипировку, расход зелий, расчёт урона, целостность сохранений и безопасный вывод имени персонажа.

🎮 Эпическая RPG игра для Telegram Mini App

## 🎯 Возможности

- ⚔️ 3 класса персонажей (Воин, Маг, Лучник)
- 🗺️ Карта мира с 5 локациями
- 👹 Боевая система с анимациями
- 🎒 Инвентарь и магазин
- 📜 Система квестов
- 🏆 Достижения
- 🏰 Подземелья с боссами
- 💾 Автосохранение
