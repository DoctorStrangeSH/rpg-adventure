# RPG Adventure - Telegram Mini App

🎮 Эпическая RPG игра для Telegram Mini App

## 🎯 Возможности

- ⚔️ 3 класса персонажей (Воин, Маг, Лучник)
- 🗺️ Карта мира с 5 локациями
- 👹 Боевая система с анимациями
- 🎒 Инвентарь и магазин
- 📜 Система квестов
- 🏆 Достижения
- 🏰 Подземелья с боссами
- 💾 Автосохранение

## 🚀 Запуск

```bash
# Локально
python -m http.server 8000

# Или через Node.js
npx serve
