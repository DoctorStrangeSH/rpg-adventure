## В работе

### Тактический ИИ противников
- [x] Волки телеграфируют прыжок, когда здоровье героя опускается до 40% или ниже.
- [x] Гоблины чаще выбирают истощение при запасе маны героя от 40%.
- [x] Скелеты снимают один эффект (горение, яд, кровотечение или ослабление) либо восстанавливают здоровье при низком запасе HP.
- [x] Специальные атаки обычных врагов заранее предупреждают игрока и могут быть прерваны заморозкой.
- [x] Враги учитывают класс и броню героя: гоблины чаще давят на ману магов, волки раньше атакуют лёгких лучников, великан выбирает пробивание тяжёлой брони.
- [x] Мини-боссы получают узнаваемые последовательности атак после фирменного приёма (засада → истощение, удар великана → восстановление, похищение жизни/пламя → тяжёлый удар).
- [x] Уникальные сигнатурные атаки сюжетных боссов: шипастые корни хранителя, огненное дыхание горного дракона, похищение жизни лича и катаклизм Пожирателя миров.
- [x] Защита от мгновенного поражения героя с полным HP одной фирменной атакой сюжетного босса (не более 80% максимального HP за удар).
- [ ] Ручная проверка сложности сюжетных боссов и наград в реальных забегах.
- [x] Редкие сочетания двух элитных свойств: кровопийца + ярость, броня + адаптация, ярость + броня; способности работают одновременно.
- [ ] Балансировка частоты адаптации и силы специальных атак.

### Подземелья и развитие забегов
- [x] Три дополнительных события подземелий: кровавый договор, астральная рукопись и привал странников с риском или платой ресурсами.
- [ ] Больше значимых событий, развилок и редких встреч.
- [x] Тематическая добыча сюжетных боссов: с вероятностью 65% региональная экипировка, иначе обычная таблица предметов.
- [x] Ледяная кираса получает пассивный ответный эффект: 15% шанс заморозить атаковавшего врага при получении урона с учётом иммунитетов.
- [x] Кровавый панцирь охотника: 25% шанс восстановить 20% полученного урона (не более 10% максимального HP), только если герой выжил.
- [x] Полные комплекты пепла, стужи и крови повышают на 10 процентных пунктов шанс эффекта соответствующего оружия.
- [x] Драконий меч: после критической обычной атаки наносит дополнительный удар (25% исходного урона, не выше 8% максимального HP врага).
- [x] Лунный клинок: критический удар восстанавливает до 8 маны, не превышая максимальный запас.
- [ ] Другие предметы с самостоятельными механиками, балансировка пассивных эффектов.
- [x] Привал каждые пять этапов позволяет безопасно вернуться и позже возобновить экспедицию с сохранённой точки.
- [x] На карте отображаются сохранённая контрольная точка и кнопка продолжения с конкретного этапа.
- [ ] Длинные забеги с нарастающей сложностью и понятными контрольными точками.
