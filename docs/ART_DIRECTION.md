# RPG Adventure — Сумеречная готика

Статус: утверждённое художественное направление, первый этап внедрения.

## Визуальный язык

- Детализированный, чёткий пиксель-арт без размытия и смешения масштабов пикселей.
- Окружение: древняя готика, руины, тёмный лес, мох, витражи, лунный свет.
- Силуэты: выразительные chibi-герои, читаемое оружие, различимая экипировка и враги.
- Материалы: тёмный камень, серебро, золото с патиной, бордовая ткань.
- Интерфейс: тёмные панельные поверхности, тонкое состаренное золото, достаточно крупные интерактивные элементы для Telegram.

## Технические правила

- Изображения должны храниться локально в репозитории, без внешних CDN.
- Сначала добавлять и подключать новый ресурс с резервной отрисовкой, затем удалять устаревшие примитивы.
- Оптимизировать большие задники в WebP; прозрачные спрайты и исходники анимаций хранить отдельно.
- Не затрагивать сохранения, баланс и игровой прогресс ради графики.
- На каждом этапе запускать `npm test`, затем проверять кадры вручную на мобильном соотношении сторон.
