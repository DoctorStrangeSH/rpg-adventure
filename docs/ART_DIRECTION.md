# RPG Adventure — Сумеречная готика

Статус: утверждённое художественное направление, первый этап внедрения.

## Визуальный язык

- Детализированный, чёткий пиксель-арт без размытия и смешения масштабов пикселей.
- Окружение: древняя готика, руины, тёмный лес, мох, витражи, лунный свет.
- Силуэты: выразительные chibi-герои, читаемое оружие, различимая экипировка и враги.
- Материалы: тёмный камень, серебро, золото с патиной, бордовая ткань.
- Интерфейс: тёмные панельные поверхности, тонкое состаренное золото, достаточно крупные интерактивные элементы для Telegram.

## Технические правила

- Изображения должны храниться локально в репозитории, без внешних CDN.
- Сначала добавлять и подключать новый ресурс с резервной отрисовкой, затем удалять устаревшие примитивы.
- Оптимизировать большие задники в WebP; прозрачные спрайты и исходники анимаций хранить отдельно.
- Не затрагивать сохранения, баланс и игровой прогресс ради графики.
- На каждом этапе запускать `npm test`, затем проверять кадры вручную на мобильном соотношении сторон.

- [x] Исправлен crossfade иллюстрированных состояний: базовая поза затухает ровно настолько, насколько проявляется attack/guard-атлас; устранено наложение двух полностью непрозрачных спрайтов. Если ресурс или кадр недоступен, остаётся idle PNG либо Canvas fallback.

## Слои экипировки

- Для трёх классов определены стабильные локальные точки крепления weapon, shield и back.
- Точки различаются по idle/attack/guard, чтобы будущие отдельные PNG оружия не плавали относительно рук.
- Базовая высота координат персонажа — 100 px; якоря являются метаданными и не рисуют заглушки поверх существующего арта.
- Переходы слоёв используют smoothstep-кривую с нулевой скоростью на старте и завершении.

- [x] Добавлен runtime-контракт отдельных слоёв экипировки: регистрация PNG-изображений для back/weapon/shield, отрисовка в стабильном порядке и масштабирование с сохранением пропорций по pose-aware якорям. Ресурсы опциональны; пустые/не загруженные изображения пропускаются.

- [x] Добавлена асинхронная загрузка внешних PNG-слоёв экипировки с обработкой ошибок и удалением слоя; незагруженный ресурс не отображается и не мешает остальным слоям.
