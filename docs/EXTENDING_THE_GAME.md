# Как расширять RPG Adventure

Этот гайд описывает безопасный путь добавления контента и систем. Он не расширяет scope 1.0.

## Новый враг

Добавьте объект в `ENEMIES` в `js/data/enemies.js`: уникальный ID, имя, здоровье, атаку, защиту и награды. Валидатор `ENEMY_REGISTRY` проверит обязательные поля. Если враг участвует в этапах, добавьте ID в данные соответствующей локации и проверьте боевое поведение.

```js
{
    id: 'ash_wraith',
    name: 'Пепельный призрак',
    icon: '👻',
    behavior: 'aggressive',
    health: 120,
    attack: 24,
    defense: 8,
    expReward: 90,
    goldReward: 70
}
```

## Новый предмет

Добавьте запись в `ITEMS` в `js/data/items.js`. Обязательны `id`, `name`, `type`, `rarity`, `price`. Эффекты должны использовать существующие обработчики; новый тип эффекта требует отдельной реализации и тестов.

## Новый квест или достижение

Добавьте определение в `QUESTS` или `ACHIEVEMENTS`. Не переиспользуйте старые ID для нового смысла. Награды должны ссылаться на существующие ID предметов. Система миграции прогресса дополняет сохранение новыми записями по ID; тестируйте прогресс, завершение, выдачу и защиту от повтора.

## Новый регион

Добавьте запись в `LOCATIONS` с уникальным ID, этапами, врагами и наградами. Проверьте ссылки, требования уровня, карту, разблокировки и контрольные точки. Изменение маршрута кампании требует отдельного Change Request; новые регионы после 1.0 планируются отдельно.

## Новая игровая система

1. Создайте отдельный модуль в `js/systems`.
2. Определите публичные функции и входные/выходные данные.
3. Не импортируйте UI в систему и не меняйте DOM из неё.
4. Храните runtime-состояние отдельно от декларативных определений.
5. Если меняется формат сохранения, увеличьте `CURRENT_SAVE_VERSION` и добавьте миграцию следующей версии.
6. Добавьте unit-, integration- и migration-тесты.
7. Подключайте интерфейс только через публичный API.

## Перед слиянием

- [ ] ID уникальны, стабильны и проходят валидацию.
- [ ] `validateContentReferences()` не находит битых ссылок между регионами, врагами и наградами.
- [ ] Все ссылки на контент разрешаются.
- [ ] Полный `npm test` проходит.
- [ ] Старые сохранения загружаются без потери прогресса.
- [ ] Нет импортов UI из core/data/systems.
- [ ] Документация обновлена.
- [ ] Изменение scope одобрено через Change Request.
