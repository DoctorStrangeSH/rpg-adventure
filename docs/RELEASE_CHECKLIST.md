# Release Checklist — RPG Adventure 1.0

Релиз разрешён только после подтверждения каждого MUST из `docs/PROJECT_SPEC.md`.

## Качество
- [ ] GitHub Actions на финальном commit — зелёный.
- [ ] `npm test` проходит.
- [ ] Нет блокирующих ошибок в консоли.
- [ ] Нет известных crash, soft-lock, потери или дублирования прогресса.

## Прохождение
- [ ] Воин прошёл всю релизную кампанию.
- [ ] Маг прошёл всю релизную кампанию.
- [ ] Лучник прошёл всю релизную кампанию.
- [ ] Проверены обычный бой, элитный бой, босс, победа, поражение и выход.
- [ ] Проверены события, контрольные точки, награды и финал кампании.

## Сохранения и экономика
- [ ] Новое сохранение создаётся и загружается.
- [ ] Существующее сохранение мигрирует/загружается без потери.
- [ ] Награды не дублируются.
- [ ] Покупка, экипировка, расходники, улучшение, разбор, крафт и руны проверены.

## Интерфейс
- [ ] Telegram WebView на узком телефоне проверен.
- [ ] Desktop browser проверен.
- [ ] Все экраны прокручиваются, тексты не обрезаны, кнопки доступны.
- [ ] Загрузка, ошибки и пустые состояния имеют понятную обратную связь.

## Выпуск
- [ ] OPEN DECISION закрыты или явно исключены из версии 1.0.
- [ ] README и версия обновлены.
- [ ] Известные некритические ограничения перечислены.
